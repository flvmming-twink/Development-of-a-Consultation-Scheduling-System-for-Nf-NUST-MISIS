# Обновление от 26.09.2026

## Excel-выгрузка пользователей

В разделе «Пользователи» администратору доступна выгрузка `.xlsx`:

- только студенты;
- только преподаватели;
- все пользователи на отдельных листах «Студенты», «Преподаватели» и «Администраторы»;
- по отдельному флажку в выгрузку включаются учётные записи из корзины.

Файл содержит структурированные ФИО, группу или кафедру, курс, форму обучения,
дисциплины, статус и даты жизненного цикла. Пароли и их хеши не выгружаются.

## Обучающие видео

Администратор управляет тремя независимыми ссылками в разделе «Обучающие видео»:
для студента, преподавателя и администратора. Поддерживаются публичные, доступные
по ссылке и приватные RUTUBE-видео с ключом `p`.

При первом входе пользователя открывается диалог с видео его роли. После закрытия
диалог автоматически больше не появляется. Повторный просмотр без ограничений
доступен в настройках. Если ссылка не задана, RUTUBE не отвечает или ролик удалён,
показывается сообщение о временной недоступности.

## Развёртывание

Миграция `0006` добавляет таблицу `tutorial_videos` и поле
`users.tutorial_seen_at`. Перед запуском новой версии необходимо выполнить:

```bash
alembic upgrade head
```

Для встроенного плеера политика Content Security Policy разрешает только кадры
с `https://rutube.ru`. Произвольные видеохостинги и HTML-код iframe не принимаются.
