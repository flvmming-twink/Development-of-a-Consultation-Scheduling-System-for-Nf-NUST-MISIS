## Среда и пределы проверки

Использовались Python 3.12.14, Flask 3.1.2, SQLAlchemy 2.0.52, psycopg 3.2.10,
pytest 8.4.2 и PGlite 0.5.8 с btree_gist через pglite-socket 0.2.11.
[PGlite](https://pglite.dev/) — сборка PostgreSQL для WebAssembly. В готовом проекте
нет зависимости от PGlite: поставляемое приложение работает с PostgreSQL через psycopg.

Обычный сервер PostgreSQL и Docker на стенде не были доступны для запуска.
Два пропущенных pytest-сценария: параллельная запись на последнее место и обработка
отката после SQL-ограничения через штатный драйвер PostgreSQL. Само срабатывание
исключающих ограничений проверено отдельно через SQL, как указано выше.

Запуск Chromium на стенде завершался ошибкой окружения до открытия страниц.
Поэтому визуальная проверка сайта в браузере, мобильный вид и выполнение JavaScript
в браузере не отмечены как пройденные. HTML-шаблоны всех основных страниц отрисованы
в функциональных тестах; CSS и JavaScript поставляются в исходниках.

Не заявляются выполненными: запуск на компьютере пользователя, полноценный Docker-запуск,
испытание в локальной сети вуза, нагрузочные измерения, резервное восстановление
на обычном PostgreSQL и публикация на сервере. Для них приложены команды и календарные задачи.

## Как повторить проверки

Создайте отдельную PostgreSQL БД `consultations_test`. Установите
`requirements-dev.txt`, задайте `TEST_DATABASE_URL` и выполните `python -m pytest -q`.
Инструкции находятся в корневом README.md. Не задавайте `SKIP_CONCURRENCY` и
`SKIP_NATIVE_CONSTRAINTS` при запуске на обычном PostgreSQL: тогда выполняются все 23 теста.
Тестовая база очищается во время испытаний, поэтому рабочую БД использовать нельзя.

Для ручной приёмки пройдите раздел «Первая проверка за 15 минут» в START_HERE.md.
Рекомендуемые размеры окна для проверки интерфейса: 1440 × 1000 и 390 × 844.
Проверьте три роли, формы, светлую/тёмную темы и отсутствие горизонтального прокручивания
страницы на телефоне. Широкие таблицы имеют собственную область прокрутки.
